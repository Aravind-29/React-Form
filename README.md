# React Form with Client-Side Validation
This project demonstrates how to build and validate a form with client-side validation in a React.js application. The form dynamically handles user inputs, validates them, and displays the submitted data below the form in real time.

## Features
- Dynamic Form Rendering: User-friendly form for collecting data.
- Client-Side Validation: Ensures valid inputs before submission.
- Real-Time Display: Displays submitted data below the form dynamically.

## Technologies Used
- React.js: Framework for building the UI.
- JavaScript (ES6+): For form logic and validation.
- CSS: For styling the form and responses.
## Setup Instructions
Follow these steps to run the project locally:

- **Step 1: Clone the Repository**
```
git clone https://github.com/YourUsername/Form-Validation-App.git
cd Form-Validation-App
```
- **Step 2: Install Dependencies**
```
npm install
```
- **Step 3: Start the Application**
```
npm start
```
The app will be available at http://localhost:3000.


## Challenges Faced
- Implementing validation that works in real-time without blocking the form submission.
- Creating reusable and scalable form components.
